# Docs

## `epics/`

Planned and in-progress work. One file per epic, prefixed with the date it was
started: `YYYY-MM-DD-short-name.md`.

Use checkboxes so progress can be ticked off as work happens:

```markdown
- [ ] Not started
- [x] Done
```

## `archive/`

Completed epics. When every box in an epic is ticked, move the file here and set
its status to `Complete` with a completion date:

```bash
git mv docs/epics/2026-08-29-form-submission-fix.md docs/archive/
```
